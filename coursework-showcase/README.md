## How this work fits together

My CS foundation came before my current work with coding agents. These selected assignments show the smaller programs and explicit data structures behind that foundation; my larger projects explore what I can build with AI-assisted workflows.

The coursework originally lived on my computer and was uploaded to GitHub together in November 2026. The upload date is not its development date. This collection preserves the exercise code and its comments; the README layout and explanations were prepared with AI assistance.

Coursework can include assignment scaffolding and supplied sample data. My authorship refers to my student implementations, not ownership of every course-provided element. See [source notes](SOURCES.md) for dates, original locations and the exact files selected.

## Running the projects

Clone this repository, then follow the commands on each project page:

```sh
git clone https://github.com/scolety1/scolety1.git
cd scolety1/coursework-showcase
```

Java projects use JDK 17 or later. C++ examples use a C++17 compiler. Python examples use Python 3; only the card analyzer requires NumPy. Commands were checked against the source layout but have not been executed for this extraction; these are preserved coursework examples rather than production releases.
