## Original work and presentation

These are selected coursework implementations from before October 2025. Spencer Colety identifies this period as primarily hand-coded work, with occasional assistance possible. This is not a claim that every line of course scaffolding or every supplied data file was independently authored.

The Java projects come from archives labeled Fall 2024 and Spring 2025. Those course periods and the owner's account establish their placement here; the November 2026 bulk-upload commits do not reconstruct the original development history. The Python labs have internal October 17 and November 28, 2023 dates. The C++ examples come from the Spring 2024 archive the owner identified as hand-coded coursework. They remain labeled as practice examples, with any course-provided structure retaining its attribution.

Only the project source and small runtime inputs listed below were extracted. Lectures, class rosters, course PDFs, screenshots and unrelated assignments were not included. No new license is imposed on course-provided material. Original comments and names are retained.

The code was read during selection and copied without changes. New project names, directory packaging and README explanations were prepared with AI assistance. No compilation, runtime execution or fresh test pass is claimed for this extraction.
